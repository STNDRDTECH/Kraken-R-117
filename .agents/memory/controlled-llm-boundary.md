---
name: Controlled LLM proposal boundary
description: Durable authority and evaluation constraints for the candidate-only model adapter.
---

Model output may only be a declared proposal, reasoning, and an authorized
bounded route hint. It is never evidence, execution, settlement, confidence,
goal, persistence, learning credit, or controller authority. Context projection
requires a fully validated candidate-authorized constitutional trace; invalid
provider identity, model provenance, context, route hint, output, deadline, or
replay disposition must fail closed.

**Why:** Provider generation is nondeterministic and self-report cannot
constitute external evidence or settlement. Candidate-only isolation prevents a
model call from silently becoming a live ROGAL authority path.

**How to apply:** Keep provider injection stateless. Structural replay verifies
recorded hashes and disposition without calling a provider. Any future
comparison must hold provider identity/configuration, prompt controls, and
available token accounting consistent across base, mediated, and reset-routing
conditions; report observations without claiming performance improvement until
independent execution-grounded evidence exists.
